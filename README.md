## Getting Started

```bash
git clone https://github.com/Bannysukumar/kait.org.git
cd kait.org
npm install
npm run dev
```

Scripts defined in package.json:

- `npm run dev` — `next dev --turbopack`
- `npm run build` — `next build`
- `npm run start` — `next start`
- `npm run lint` — `next lint`
